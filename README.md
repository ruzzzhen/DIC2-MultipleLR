# Multiple Linear Regression Explorer（多元線性迴歸探索器）

- **GitHub Pages**：<https://ruzzzhen.github.io/DIC2-MultipleLR/>
- **GitHub Repository**：<https://github.com/ruzzzhen/DIC2-MultipleLR>

這是一個**多元線性迴歸分析網站**：用好幾個欄位（特徵）去預測一個數字（目標），並找出**哪幾個欄位最值得用**。

重點在於「欄位不是越多越好」。放進太多不重要的欄位，模型雖然在訓練資料上看起來更準，遇到沒看過的資料反而會變差，這就是**過擬合**。這個網頁就是要找出準確度和精簡程度之間最好的平衡點。

分析流程：

1. **切分資料**：80% 當訓練集用來建立模型，20% 當測試集用來檢驗模型。
2. **排序特徵**：用 5 種特徵選擇方法，排出欄位的重要程度。
3. **逐一比較**：從 1 個欄位開始，一路試到全部欄位，每一種都建立迴歸模型，並計算測試集上的誤差。
4. **找出最佳解**：測試誤差最小的欄位數量會標成 **★ Sweet Spot**，圖表也會標出「欄位加太多反而變差」的位置。

網站內建兩個題目（新創公司利潤、醫療保險費用），也可以貼上自己的 CSV 網址來分析。所有計算都在瀏覽器裡完成，打開網頁就能直接使用。

## 網頁上可以看到什麼？

| 區塊 | 用白話說 |
|---|---|
| **Problem 下拉選單** | 切換要看哪一個題目（第 1 題 / 第 2 題 / 自己的資料） |
| **Custom Dataset** | 貼上任何 CSV 檔的網址，網頁就會用你的資料重新分析 |
| **演算法按鈕** | 選擇用哪一種方法排出欄位的重要順序，或選「Compare All」一次比較 5 種 |
| **k 按鈕** | k 是「用幾個欄位」，點不同的 k 看結果怎麼變 |
| **指標卡** | 模型準不準：平均錯多少（RMSE、MAE）、解釋了多少變化（R²）、模型整體有沒有意義（F 檢定） |
| **折線圖** | 欄位數量 vs. 準確度，找出最低點（最好）和過擬合的地方 |
| **迴歸方程式** | 最後得到的預測公式，例如：利潤 = 46,346 + 0.79 × 研發費 + 0.03 × 行銷費 |
| **係數表** | 每個欄位影響多大、這個影響是不是「真的」（p-value）、欄位之間會不會太像（VIF） |
| **即時預測器** | 拉動滑桿輸入數字，馬上看到預測結果 |
| **殘差表** | 列出考試時猜得最不準的 10 筆資料 |

## 兩個題目

### 第 1 題：預測新創公司的利潤（50 Startups）
- 50 家公司，欄位：研發費、行政費、行銷費、所在州。
- **結論：只用「研發費 + 行銷費」2 個欄位最準**（平均誤差約 $8,199）。
  把 5 個欄位全部放進去，誤差反而變大到約 $9,138 → 這就是過擬合。

### 第 2 題：預測醫療保險費用（Insurance）
- 1,338 位保戶，欄位：年齡、性別、BMI、小孩數、是否抽菸、居住地區。
- **結論：影響最大的是「有沒有抽菸」，其次是年齡、BMI、小孩數。**
  這題用全部欄位時最準，沒有過擬合；但只用前 4 個欄位，準確度就幾乎一樣（差距不到 1%），是更精簡的選擇。

## 怎麼用自己的資料？

1. 在 **Custom Dataset** 貼上 CSV 檔的網址（GitHub 上的檔案請用「Raw」連結）。
   也可以直接點下方的範例按鈕試試看。
2. 按 **Load Dataset**。網頁會自動：
   - 判斷哪些欄位是數字、哪些是文字分類（例如州名），文字分類會自動轉成 0/1 的欄位。
   - 跳過有缺值的資料列，並告訴你跳過了幾筆。
3. 在 **Target column (y)** 選你想預測的欄位，就會重新分析。

如果網址錯誤、檔案不是 CSV、只有一欄、資料太少……網頁會顯示紅色的錯誤說明，不會壞掉。

## 5 種挑欄位的方法（簡單版）

| 方法 | 白話解釋 |
|---|---|
| **Lasso** | 逐步放寬限制，看哪個欄位最先「冒出來」，越早出現越重要 |
| **ElasticNet** | 跟 Lasso 類似，但對彼此很像的欄位比較寬容 |
| **Forward SFS** | 從 0 個開始，每次加入「最有幫助」的那一個 |
| **RFE** | 從全部開始，每次踢掉「最沒用」的那一個 |
| **Exhaustive Search** | 所有組合全部試一遍（欄位 ≤ 8 個時才開放，不然組合太多） |
