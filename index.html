Multiple Linear Regression CRISP-DM Project

Developed for multiple linear regression model selection, parsimony validation, and statistical inference. Built with pure Vanilla HTML, CSS, JavaScript, and Chart.js — all statistics are computed in the browser.

CRISP-DM workflow:

  1. Business Understanding — predict the target and find the smallest model that does it well.
  2. Data Understanding — fetch the CSV, detect numeric / categorical columns, count rows & missing values.
  3. Data Preparation — drop incomplete rows, one-hot encode categoricals (drop first), 80/20 split (seed 0).
  4. Modeling — Lasso, Forward SFS, RFE, ElasticNet and Exhaustive Search rank features; OLS refit for every k.
  5. Evaluation — test RMSE / R² / Adj. R² / MAE, F and t tests, 95% CI, VIF, residual diagnostics.
  6. Deployment — static website with a live predictor for the selected model.
